# تصاویر ارسالی برای ریل‌ها

هر شب ایجنت موضوع‌های فردا و فهرست تصویرهای لازم را می‌فرستد؛ هر درخواست یک شناسه دارد (مثل `R1-a`).

1. تصویر را از صفحه‌ی منبعی که ایجنت معرفی کرده ذخیره کن.
2. در GitHub به `incoming/YYYY-MM-DD/` برو (لینک آپلود در پیام شب قبل هست) و با **Add file → Upload files** آپلود کن.
3. نام فایل = شناسه‌ی درخواست، مثل `R1-a.jpg` (jpg / png / webp). حداقل ۱۰۸۰ پیکسل در ضلع کوچک‌تر.
4. تا ساعت ۰۵:۰۰ صبح. اگر تصویری نرسید، آن صحنه با حرکت وکتور ساخته می‌شود و ریل عقب نمی‌افتد.

مسئولیت حق استفاده از تصویر با فرستنده است؛ منبع هر تصویر در کپشن ذکر می‌شود.
