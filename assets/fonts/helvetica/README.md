Helvetica-style Latin font for English reels.
Currently TeX Gyre Heros (free Helvetica clone, GUST Font License; LICENSE.txt). Helvetica itself is a commercial typeface
(Monotype); to use the real one, add licensed files here (e.g. HelveticaNeue-Regular.otf, -Medium, -Bold) and point
brand_config.json fonts.latin.files at them. Nothing else needs to change.
